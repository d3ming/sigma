# Sigma verification map

Read the relevant feature before driving. These recipes describe the shipped UI and CLI; the driver’s fictional
fixture supplies one recent picked episode, one key insight and two narrative sections. It has no X edition or
directional sentiment. Unseeded paths remain unverified until their documented prerequisites are supplied.

Use the isolated launch and doctor in [verify](../SKILL.md). Run from the source checkout with an absolute scratch
path. Browser proofs use fresh contexts, desktop 1280 and mobile 390 widths, and the recorded instance URL.
`reading` and `picks` are executable driver features; the other recipes name real commands/controls for a later
source-backed verification. Do not mistake this index for completed coverage.

- [Episode reading](reading.md): home disclosure, full narrative and direct detail entry.
- [Find and picks](find-and-picks.md): homepage chip, direct Find, query/filter intersection and episode badge.
- [One-off ingestion](one-off-ingestion.md): cached URL intake, duplicate protection and scope of its side effects.
- [X evidence](x.md): edition navigation, theme citations and source disclosures.
- [Sentiment](sentiment.md): ordered company votes and underlying speaker evidence.

Proof includes actions and resulting state, screenshots/ARIA and trace, command results and relevant file changes.
Run cleanup after failure too. Evidence survives cleanup under the launch’s `evidence/` directory. Never publish
fictional seed data, drive a shared browser session or infer coverage from an empty page.
