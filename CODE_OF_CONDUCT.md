# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; it applies to all project spaces, including issues, pull requests and discussions.

To report a problem, use a private GitHub security advisory on this repo (Security tab, **Report a vulnerability**), or
open an issue that asks for a private channel and leave out the details. The maintainers are responsible for enforcement.
