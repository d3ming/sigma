# Use Sigma's evidence

Start at the site's `/llms.txt` for the page and data indexes. Pages have Markdown counterparts; structured feeds preserve the speaker, timestamp and source link. Follow those links when a claim matters to a decision.

A local library contains only what the operator has ingested. Use `sigma library --help` to query it and inspect its date range before assuming it is current. A clone alone contains no private library or published history.

Claims are checked against transcripts, not filings or prices. A transcript can misspell a name, omit context or mishear a figure; source grounding does not make a speaker's claim true. When a name is uncertain, use the role rather than inventing an attribution.

Signals report what public sources said. They are not the operator's positions or instructions to trade. Missing data stays missing, and an incomplete day names its missing source rather than borrowing an older day's values.
